# IPL Performance Analytics & Match Insights

## Overview
This project performs comprehensive IPL data analytics using Python, exploratory data analysis (EDA), statistical techniques, and Power BI visualizations.

## Features
- Toss Impact Analysis
- Match Phase Analysis
- Top Batters & Bowlers
- Death Over Analytics
- Venue Analysis
- Consistency Analysis

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- Google Colab

## Key Insights
- Death overs showed highest strike rates
- Middle overs generated highest total runs
- Economical death bowlers heavily influenced outcomes
